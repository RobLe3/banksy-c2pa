# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-23

- Initial public-source release.
- Added local ES256 C2PA attestation and derivative workflows for PNG and JPEG.
- Added macOS login Keychain storage with LocalAuthentication user-presence checks.
- Added interactive menu, batch status/signing, container auditing, and byte-preserving evidence packages.
- Added customizable signer identity with backward compatibility for earlier private profiles.
- Added post-write semantic, cryptographic, pixel, container, and hash validation.
